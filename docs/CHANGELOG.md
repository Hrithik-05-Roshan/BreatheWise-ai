# Changelog — BreatheWise AI

## [1.0.0] - 2026-11-21
### Added
- **Landing Page:** Interactive city simulation visualizer, problem awareness, 6 intelligent product pillars.
- **Onboarding Wizard:** 6-step personalized setup with local-first browser storage.
- **Command Center Dashboard:** CPCB NAQI gauge, 4-window diurnal schedule, 8-part structured recommendations feed, hourly trend chart, and interactive safety checklist.
- **Indoor Air Intelligence:** Room-by-room clean air audit, cooking gas ventilation guidelines, HEPA placement protocols.
- **Smart Commute Assistant:** 5-way transport mode comparison evaluating respiratory exposure versus Central Electricity Authority (CEA) carbon baselines.
- **Sustainability & Habit Tracker:** Errands trip-chaining optimization and community habit challenges.
- **BreatheWise Intelligence AI:** Server-side conversational assistant with prompt injection defenses and deterministic fallback.
- **Quality Architecture:** React Error Boundaries, WCAG 2.2 AA skip navigation links, and dynamic chart chunking.
- **Automated Test Suite:** 34 Vitest unit, integration, security, and accessibility tests + 3 Playwright browser E2E tests.
