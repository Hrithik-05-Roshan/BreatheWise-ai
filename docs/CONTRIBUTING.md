# Contributing Guidelines

## 1. Code Standards
- All code must pass strict TypeScript compilation (`npm run typecheck`).
- Code must adhere to existing Tailwind utility conventions and accessible component patterns.
- New domain rules or calculators must include corresponding unit tests in `tests/unit/`.

## 2. Commit Conventions
We follow conventional commits:
- `feat:` New user-facing feature or enhancement
- `fix:` Bug fix or calculation correction
- `test:` Adding or updating automated tests
- `docs:` Documentation improvements
